# PXL
`PXL` (pronounced `pik·sl`) is a header-only image processing library in `C++20`.

To start off working in a guided sandbox, use the command below or click on `launch binder` badge above:

```
docker run -p 8888:8888 -it --rm asobhani/pxl
```
